# Three.js TSL template

Minimal WebGPU + TSL starter: one torus, one `MeshStandardNodeMaterial`, `colorNode` driven by TSL.

Edit `src/material.js` to change the shader graph. Tweakpane in the top-right binds the color uniforms.

## Setup

```bash
npm install
npm run dev
npm run build
```
